# choimory-dev

- 개인 공부용
- 공부하고 싶거나 필요한 기능들 하나씩 추가

# 주요기능

- 회원 -> 팔로잉, 개인 SNS
- 포스트 -> 회원별 개인 포스팅
- 게시판 -> 카테고리별 공용 게시판
- 메모 -> 개인 private 메모
- 알림 -> 팔로잉, 댓글 등에 대한 알림
