# 개요

- choimory.dev는 나만의 플랫폼
- 내가 필요하거나 쓰고 싶은, 혹은 공부용으로 개발하고 싶은 여러 기능들을 플랫폼 하위 서비스로 붙임 (블로그, 메모, 피드, 가계부, 일정 등등..)
- 만들고 싶은 기능들을 플랫폼 하위 서비스로 그때 그때 추가하며 확장

# 서비스

- 피드 (가격알림, 활동알림, 신곡알림)
