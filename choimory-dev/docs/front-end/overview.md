# 개요

- front, admin, mobile 세개
- 향후 플랫폼 하위 서비스별로 프론트 프로젝트 분리해야할 수도?
- admin은 하나만 놓고 전체 관리
- 프론트가 서비스별로 분리된다면 mobile도 서비스별로 분리?

# choimory-dev-front

- next.js 
- choimory-dev 플랫폼 및 하위 서비스 
- 향후 플랫폼 하위 서비스들을 별로 프론트 프로젝트로 분리한다면, 플랫폼 전용 프론트 프로젝트로 사용

# choimory-dev-admin

- next.js
- choimory-dev 플랫폼 및 하위 서비스 모두 제어
- 분리계획 없음

# choimory-dev-mobile

- react native
- choimory-dev 플랫폼 및 하위 서비스 모바일
- 향후 플랫폼 하위 서비스들을 별로 모바일 프로젝트로 분리한다면, 플랫폼 전용 모바일 프로젝트로 사용
